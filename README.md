**Live app**: https://zaply-app.lovable.app

## Build with Lovable

Continue developing this project in the [Lovable editor](https://lovable.dev/projects/2bc7c7cd-fdab-409c-a67d-231d61a13c6f).

## Development

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
